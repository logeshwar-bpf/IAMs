# Google Workspace IAM & User Access Management

A specialized access management system for Google Workspace enterprise domains, user licensing, service assignments, and bulk role management.

## Features
- **User Directory & Service Assignment:** Manage Google Workspace users, license allocations, and service access.
- **Bulk Actions:** Assign or revoke Google Workspace services (Gmail, Drive, Calendar, Vault, etc.) across multiple users.
- **Modals & Create User Workflows:** Streamlined user creation and delegation tools.
- **API Integration:** Built-in REST endpoints for user licensing, bulk updates, and domain policy sync.

## Tech Stack
- **Framework:** Next.js / React
- **Language:** TypeScript
- **Styling:** Tailwind CSS / Custom UI Components

## Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation & Development
```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to access the dashboard.
